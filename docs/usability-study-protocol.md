# Usability study protocol (proposal implementation aid)

This is a protocol template, not study evidence. Do not recruit or collect personal data until the university/supervisor confirms the required ethics approval, consent language, and data-retention rules.

## Study question

Can a non-technical SaaS founder request an isolated cloud environment, understand its status, and interpret its budget/governance information using the Cloud-in-a-Box portal?

## Participant tasks

1. Open the public portal and submit a Development environment request using supplied fictional test details.
2. Save the private request reference/token and return to view status/history.
3. Locate the tenant region, subscription status, requested budget alert, and provisioning outcome.
4. If an administrator test account is provided, inspect resource verification, identify a failed check, and export the evaluation evidence.
5. Explain whether the displayed Azure budget alert stops spending (correct interpretation: it does not).

Use a disposable test subscription and data that do not identify real customers. Never give study participants a production admin key or live tenant access.

## Measurements to record

- Task completion (success/partial/failure) and completion time for each task.
- User-reported confusion points and observed errors, using anonymized participant IDs.
- Questionnaire responses selected in the approved study plan. If using the System Usability Scale, use the validated 10-item wording and scoring method unchanged.
- Manual provisioning baseline measured with the same start/end definitions as the automated workflow.
- Portal provisioning duration and Azure policy verification results exported from the admin evidence CSV.
- Cross-tenant isolation results from an explicitly approved network test, reported separately from ordinary provisioning checks.

Do not fabricate participants, timings, baseline comparisons, policy compliance percentages, or cross-tenant test results. Publish aggregate results and limitations only after the study has been conducted and approved.
