      Administrator sign-in

      Administrator access is restricted to trusted testers. The key is not displayed or copied on this public page.

      1. Ask the platform owner to share the admin key with you privately, or ask them to retrieve it from the Azure portal’s Key Vault secret page.
      2. If you have Azure CLI and permission to read the secret, run this command in Terminal:

      az keyvault secret show --vault-name cibkvwcrzymyb --name portal-admin-key --query value -o tsv
